# Сайт «Чемпион LED»

Рабочая база знаний для проектирования и разработки сайта интернет-магазина современного функционального освещения «Чемпион LED».

## Инструкции

1. [Типографика](instructions/01-typography.md) — шрифтовые роли, иерархия, размеры, набор и правила применения.
2. [Описание проекта](instructions/02-project-description.md) — позиционирование, аудитории, задачи сайта, структура и принципы коммуникации.

## Референсы и ресурсы

- [Визуальный референс текущего сайта](references/current-site/README.md) — пять последовательных скриншотов и правила, которые они фиксируют.
- [Локальные шрифты](assets/fonts/README.md) — рабочие variable-font файлы, лицензии и примеры подключения.
- [`font-test.html`](font-test.html) — быстрая визуальная проверка Geist и Science Gothic на кириллице.
- [Первый экран](blocks/hero/index.html) — адаптивный блок «Современный функциональный свет».
- [Блок «О бренде»](blocks/brand-intro/index.html) — изображение, заголовок, текст и две кнопки.
- [Блок преимуществ](blocks/benefits/index.html) — заголовок и сетка из шести преимуществ.
- [Каталожная CTA-перебивка](blocks/catalog-cta/index.html) — текст, кнопка подбора и изображение каталогов.
- [CTA консультации](blocks/consultation-cta/index.html) — фото специалиста, описание помощи и кнопка подбора.
- [CTA консультации с попап-формой](blocks/consultation-cta-popup/index.html) — тот же блок с автономным CSS/JS и AJAX-отправкой.
- [Блок для клиента и монтажника](blocks/client-mounting-benefits/index.html) — вводный текст, две кнопки и шесть горизонтальных карточек.
- `references/source-files/current-site.pdf` — исходный цельный макет.
- `references/source-files/Site.zip` — исходный HTML/CSS-экспорт из Figma.
- `references/source-files/Geist,Science_Gothic.zip` — оригинальный архив шрифтов без изменений.

Все последующие решения по интерфейсу, текстам и верстке должны проверяться на соответствие этим инструкциям.
